# Hardware

Den aktuelle strømsensorfirmware bruger ESP32-C3 og ZMCT103C. Sensorens udgang forbindes via spændingsdeler til GPIO 4. Måle- og kalibreringskonstanter findes i `firmware/src/config.h`. Se [firmwarevejledningen](../firmware/README.md) for kalibrering.

Systemets øvrige spjældhardware beskrives i den [historiske vejledning](legacy-README.md). Fotos og diagrammer ligger i `images/`. Skilte til værkstedspanelet ligger i `panel/skilte/` fra repositoryets rod.
